# Security notes

Read README.md before operating this kit. It is a convenience wrapper for privileged, multi-host GPU workloads, not an isolation boundary. Only run it on devices and networks you are authorized to administer.

Never publish private configuration, journals, SSH keys, credentials, model caches or full unredacted logs. Do not post an exploit or secret in a public issue. Contact the repository owner privately for a security report and include only the minimum sanitized reproduction.

Downloaded third-party sources and images have their own licenses, maintainers and security policies. Fixed source identities make review possible; they do not establish that the code or image is safe. Review pin changes and rerun the tests before publishing updates.
